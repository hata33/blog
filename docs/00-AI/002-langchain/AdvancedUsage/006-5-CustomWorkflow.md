### 心智模型

自定义工作流让开发者能**完全控制执行图结构**，混合确定性逻辑与 Agent 行为，支持顺序、条件分支、循环和并行执行。核心原理是将 `create_agent` 创建的 Agent 直接作为 LangGraph 节点，在自定义图中调用，并可嵌入其他多 Agent 模式。

### 二级标题及内容

*   **【关键特征】Key characteristics**
    完全控制图结构；混合确定性逻辑与 Agent 行为；支持顺序、条件、循环、并行；可将其他模式作为节点嵌入。

*   **【使用时机】When to use**
    当标准模式（子代理、技能等）不满足需求、需混合确定性与 Agent 逻辑、或需要复杂路由或多阶段处理时使用。

*   **【基础实现】Basic implementation**
    核心是将 `create_agent` 创建的 Agent 作为 LangGraph 的节点函数，在图中直接调用 `agent.invoke()`。

*   **【示例】Example: RAG pipeline**
    一个 WNBA 统计助手的完整自定义工作流，展示三种节点类型：**模型节点**（重写查询）、**确定性节点**（向量检索，不涉及 LLM）、**Agent 节点**（基于检索上下文推理，可调用工具获取实时新闻）。通过 LangGraph State 在节点间传递数据。

### 最佳实践

*   **Agent 即是节点**：在 LangGraph 节点中直接调用 LangChain Agent，获取其灵活推理与工具调用能力，同时保留自定义图的精确控制。
*   **用 State 传递上下文**：通过 LangGraph State 在各个工作流步骤间共享和更新结构化字段，实现节点间数据流通。
*   **按需混合逻辑**：在自定义工作流中自由组合确定性步骤（如检索、计算）和 Agent 步骤（如推理、工具调用），构建最适合业务需求的混合流程。
