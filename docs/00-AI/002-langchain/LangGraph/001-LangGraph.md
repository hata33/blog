### 心智模型

LangGraph 是一个**低级编排框架和运行时**，专为构建、管理和部署**长时间运行、有状态**的 Agent 而设计。它并不抽象提示词或架构，而是专注于提供**持久化执行**、**人在回路**、**流式传输**和**全面内存**等底层基础设施。人们可以把它看作一张有向图，其中每个节点都是一个计算步骤（如 LLM 调用或工具执行），边则定义了执行流程和状态传递。

### 二级标题及内容

*   **【安装】Install**
    通过 `pip install -U langgraph` 或 `uv add langgraph` 安装。文档提供了一个最简示例：创建一个包含 `StateGraph` 的基本图，添加节点，编译后即可调用。

*   **【核心优势】Core benefits**
    *   **持久化执行**：Agent 能从故障中恢复，长时间运行并从中断处继续。
    *   **人在回路**：可在任意节点打断执行，供人类审查或修改状态。
    *   **全面内存**：既有短期工作记忆（同一线程内），也支持跨会话的长期记忆。
    *   **LangSmith 调试**：通过可视化工具追踪执行路径、捕获状态转换、提供运行时指标。
    *   **生产级部署**：为有状态、长运行工作流设计的可扩展基础设施。

*   **【生态系统】LangGraph ecosystem**
    LangGraph 可独立使用，也可无缝集成：
    *   **LangSmith 可观测性**：追踪、评估、监控部署。
    *   **LangSmith 部署**：专为有状态工作流构建的部署平台。
    *   **LangChain**：提供集成和组件，其 Agent 抽象构建于 LangGraph 之上。

### 最佳实践

*   **LangGraph 是底层运行时，通常不需要直接使用**：若刚开始构建 Agent，建议先用 LangChain 的 `create_agent` 高层抽象，它内部已使用 LangGraph。
*   **按需引入**：仅在需要精细控制图结构（如自定义工作流、复杂路由、混合确定性与 Agent 逻辑）时才直接使用 LangGraph。
*   **配合 LangSmith**：启用 `LANGSMITH_TRACING=true` 来追踪请求、调试 Agent 行为并评估输出。
*   **理解产品分层**：Deep Agents（规划、子代理）→ LangChain（Agent 框架）→ LangGraph（编排运行时）→ LangSmith（平台）。
